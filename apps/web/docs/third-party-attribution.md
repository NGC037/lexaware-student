# Third-party software and attribution

This foundation uses the following direct packages. The package lockfile pins the resolved dependency graph; consult package metadata and installed license files for the precise version shipped.

| Package | Use | License family |
| --- | --- | --- |
| React / React DOM | UI runtime | MIT |
| React Router | Browser route composition | MIT |
| Vite / `@vitejs/plugin-react` | Development server and build | MIT |
| Playwright Test | Real-browser integration tests | Apache-2.0 |
| Lucide React | UI icons | ISC |
| TypeScript | Type checking | Apache-2.0 |
| Vitest, jsdom, Testing Library | Unit and interaction tests | MIT (jsdom includes dependencies with their own licenses) |
| ESLint, typescript-eslint, React Hooks plugin | Static checks | MIT |

The brand mark and hero illustration in this foundation are original inline SVG/CSS authored in this repository. No remote stock image, copied UI kit, font download, or borrowed code snippet is used. Review transitive package notices before distributing a compiled bundle.
