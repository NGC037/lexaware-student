# LexAware Student API

FastAPI backend for the LexAware Student platform.

## Responsibilities

The API layer will provide:

- Authentication and session management
- Rights Explorer APIs
- Grounded AI Assistant APIs
- Document analysis APIs
- Complaint guidance APIs
- Help Directory APIs
- Document Vault APIs
- Administrative governance APIs

## Development

The backend uses a project-local Python virtual environment.

Activate from the repository root:

```powershell
.\apps\api\.venv\Scripts\Activate.ps1
```
